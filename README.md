
# Sieve Pattern Abilities Engine 🌀

An engine designed for calculating, exploring, and generating structural pattern abilities, benchmarks, and spatial visualizations.

---

## 📂 Project Structure

The repository is organized cleanly to separate the core engine logic from experimental runs and generated output artifacts:

```text
sieve-pattern-abilities-engine/
│
├── run_project.py           # Interactive project launcher (Run this!)
├── .gitignore               # Prevents system and byte-code tracking clutter
├── LICENSE                  # Open-source license (MIT)
├── README.md                # Project documentation
│
├── src/                     # Core Source Code (The Engine)
│   ├── __init__.py          # Marks folder as an importable Python package
│   ├── pattern_engine.py    # Main processing and calculation engine
│   └── sieve_lab.py         # Sandbox environment and utility library
│
├── experiments/             # Script Executables
│   ├── sieve_experiments.py # Core experiment runner
│   ├── sieve_explore.py     # Exploratory query script
│   └── sieve_patterns.py    # Generates pattern maps and design visuals
│
└── outputs/                 # Automatically Generated Results
    ├── benchmarks/          # Text logs and runtime performance statistics
    └── visuals/             # Exported pattern maps and graphical plots
```

## 🚀 How to Run the Project (Mobile Friendly)

You do not need to navigate deep into subdirectories or type long commands. A central interactive launcher file (**`run_project.py`**) handles the execution environment for you.

### 📱 Running via Terminal Apps (Termux, etc.)
1. Open your terminal app and navigate to the project directory:
   ```bash
   cd /sdcard/Download/sieve-pattern-abilities-engine-
   ```
2. Launch the menu controller:
   ```bash
   python run_project.py
   ```
3. Enter the number corresponding to the module you want to test (`1`, `2`, or `3`).

### 🛠️ Running via Android IDEs (Pydroid 3, Acode, etc.)
1. Open the project folder inside your editor app.
2. Open the file **`run_project.py`**.
3. Tap the **Play / Run** icon button.
4. Use the interactive console menu to choose your task.

## 📊 Modules & Outputs Breakdown

### ⚙️ Core Modules
* **`pattern_engine.py`**: The computational baseline that processes raw structural array rules and coordinates mathematical sieve generation.
* **`sieve_lab.py`**: A laboratory module for designing framework templates and parsing dynamic pattern criteria.

### 🧪 Experiments & Queries
* **Sieve Experiments (`sieve_experiments.py`)**: Runs high-throughput execution passes to verify calculation efficiency and baseline thresholds. Text tracking logs are exported directly to `outputs/benchmarks/`.
* **Sieve Explore (`sieve_explore.py`)**: Explores isolated, targeted pattern properties. Performance metrics are recorded in `outputs/benchmarks/`.
* **Sieve Patterns (`sieve_patterns.py`)**: Maps structural layouts out visually. Renders spatial `.png` vector graphs directly into `outputs/visuals/`.

---

## 🎨 Visual Results
Graphic visualizations generated by `sieve_patterns.py` and `pattern_engine.py` are saved automatically to the `outputs/visuals/` subdirectory for clean version control tracking without root folder clutter.
